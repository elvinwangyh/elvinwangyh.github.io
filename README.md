# elvinwangyh.github.io

Personal CV page for Wang Yuhui (Elvin), served by GitHub Pages at https://elvinwangyh.github.io/

## Files

| File | Purpose |
|---|---|
| `index.html` | The page (single file, no build step) |
| `cv.pdf` | Downloadable CV, linked from the page |
| `.nojekyll` | Tells GitHub Pages to serve files as-is |

## Updating

- **CV:** replace `cv.pdf` with the new file (keep the same name) and commit.
- **Page text:** edit `index.html` and update the "Last updated" line in the footer.
- Changes go live within a minute or two of each commit.

Do not commit phone numbers, position sizes or other private details: the repository and its history are public.
